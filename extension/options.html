API reference11 helpers

Actions use the right-clicked target until focus, tab or click changes it. Selectors are CSS strings.

linput.type(text)
Replace the target’s contents.
linput.enter()
Send a synthetic Enter key.
linput.tab()
Move focus to the next target.
linput.click(selector)
Click an element; update the target if an editable field receives focus.
linput.submit()
Explicitly submit a form.
linput.delay(ms)
Wait 0–60000 milliseconds.
linput.focus(selector)
Focus an editable element and update the target.
linput.value()
Return the target’s contents.
linput.exists(selector)
Check for a matching element.
linput.log(text)
Report a message in run status.
linput.split(text)
Split whitespace-separated text into a table.
Runtime & safety

Lua 5.3-like Fengari sandbox: no JavaScript access, require, io, os, debug or direct network API. Use concatenation and tostring instead of string.format.

Runs allow 5 million VM instructions, 10,000 API calls and 5 minutes. Memory limits are not guaranteed; native calls may not be interruptible. Only run scripts you trust.

No trusted keypresses: synthetic Enter is not accepted by every site. submit() can submit a real form; test on the practice page first.

Cancel with Escape, the run status, or Stop all runs. Stop active runs before changing targets.

Build once. Run from the context menu.
