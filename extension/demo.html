Try a workflow

  1. In Linput options, create a named workflow and replace its script with the Lua example below.
  2. Save the workflow. Optionally use the separate list converter to prepare a different Lua table and insert it into your script.
  3. Right-click a field below and choose your workflow from Linput's context menu.
local items = {"apple", "banana", "cherry"}
for _, item in ipairs(items) do
  linput.type(item)
  linput.delay(1000)
end

The entire script runs once; the explicit loop replaces the target's value for each item, ending with cherry. Try linput.tab() to move between fields or linput.focus("#demo-notes") to choose the notes field. linput.click("#demo-notes") can also change the target.

Synthetic Enter is not accepted by every site. linput.submit() may submit this form and reload the page. Press Escape or use Stop all workflows in options to cancel a run, and check the status there.
